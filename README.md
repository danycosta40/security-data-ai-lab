# Security Data & AI Lab

Projeto acadêmico e experimental voltado à aplicação de Engenharia de Dados,
Ciência de Dados e Inteligência Artificial na análise de incidentes de
cibersegurança, com foco na identificação e análise de falsos positivos.

## Objetivo

Investigar como técnicas de Data Science, Machine Learning e Inteligência
Artificial Generativa podem apoiar a análise de incidentes de segurança e
a identificação de falsos positivos em operações de SOC.

## Estrutura do projeto

- `data/` - dados locais utilizados durante o desenvolvimento
- `notebooks/` - notebooks de exploração, transformação e modelagem
- `src/` - código reutilizável
- `tests/` - testes automatizados
- `docs/` - documentação do projeto

## Dados

O projeto utilizará exclusivamente datasets públicos e/ou dados sintéticos.

Nenhum dado corporativo ou confidencial será utilizado neste repositório.
